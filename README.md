# Follow-up Time Is Not a Predictor: Target Leakage, Survival Re-analysis and External Validation of Heart-Failure Mortality Models

Reproducible code for a methodological re-evaluation of machine-learning
mortality prediction on the widely used heart-failure cohort of Ahmad et al.
(2017), popularised by Chicco & Jurman (2020, *BMC Med Inform Decis Mak* 20:16).

**Main claim.** The variable `time` is the follow-up duration until death *or
censoring*. It is produced by the outcome and is unknown when a prognosis is
made. Using it as a predictor inflates classification performance. The
correct formulation is time-to-event analysis on baseline variables, and models
built this way should be checked in an independent cohort (MIMIC-III).

## Key results (development cohort, n = 299, 96 deaths)

All numbers come from `results/RESULTS_SUMMARY.md`, which is generated from the
result tables (100 paired Monte-Carlo splits; 10 × 5-fold repeated CV).

| Question | Finding |
|---|---|
| Does `time` leak the outcome? | Random forest MCC: baseline variables **0.36**; `time` alone **0.54**; baseline + `time` **0.64**; baseline + *shuffled* `time` **0.36** (no gain). The gain is specific to the outcome-coupled values of `time`. |
| Is the leakage structural? | In 100 simulated cohorts where **no** covariate affects survival, baseline variables give MCC ≈ 0.00 but `time` alone gives **0.48** (random forest): the "signal" is produced by censored follow-up itself. |
| Leakage-free performance | Harrell's C: Cox 0.70, Cox (EF + SC only) 0.69, random survival forest 0.72, gradient-boosted Cox 0.73. None differs significantly from Cox (corrected resampled t-test, all p > 0.19). IBS 0.16–0.17 vs 0.19 for the Kaplan–Meier null model. |
| Internal validation | Bootstrap optimism-corrected C: Cox 0.71, RSF 0.74, GB-Cox 0.76; calibration slope 0.83 (Cox), 0.85 (RSF), **0.68 (GB-Cox, overfitted)**. |
| Calibration and utility (out-of-fold, 90 days) | Observed/expected 0.97–1.03; net benefit above treat-all/treat-none for thresholds ≈10–45 %. |
| Proportional hazards | Schoenfeld tests flag ejection fraction and CPK (p < 0.05), which supports the non-PH models as sensitivity analyses. |
| Sample size | Riley et al. criteria require n ≥ 351; n = 299 gives expected shrinkage 0.87, which is reported as a limitation. |

External-validation results on MIMIC-III have to be generated by a user with
PhysioNet credentialed access (see below). The figures in the earlier exploratory
notebooks (`legacy/`) are **invalid** (see `docs/CODE_REVIEW_TR.md`).

## Reproduce

```bash
git clone https://github.com/elifnuroksuzz/HF-Survival-Analysis-Leakage-Revisit.git
cd HF-Survival-Analysis-Leakage-Revisit
pip install -e ".[dev]"
pytest                                                  # unit tests
python scripts/run_development.py --download            # full run, ~1-2 h on 4 CPU cores
python scripts/run_development.py --quick               # smoke test, a few minutes
```

The dataset (UCI ML Repository / Kaggle `andrewmvd/heart-failure-clinical-data`)
is verified against SHA-256 `9c73cea7…dd75912`; `--download` tries UCI and two
GitHub mirrors and accepts a copy only if the hash matches.

**Google Colab.** Both notebooks clone the code, install it, and write all outputs
to `MyDrive/HF_Revisit_Project/`, so a disconnect loses nothing. Step-by-step guide
(Turkish): [`docs/COLAB_CALISTIRMA_TR.md`](docs/COLAB_CALISTIRMA_TR.md).

### External validation (MIMIC-III v1.4)

Requires PhysioNet credentialed access linked to Google BigQuery.

```bash
pip install -e ".[mimic]"
python scripts/run_development.py --stages export          # fit final models
python scripts/run_external_validation.py --gcp-project <your-gcp-project> --horizon 90
python scripts/ef_annotation.py sample                     # then annotate, then:
python scripts/ef_annotation.py score
```

MIMIC-III extracts and patient-level outputs are git-ignored and **must not be
shared** (PhysioNet Data Use Agreement).

## Methods in brief

* **Leakage experiments.** (A) follow-up by vital status; (B) `time` alone;
  (C) baseline ± `time`; (D) shuffled-`time` control; (E) fixed-horizon
  reformulation without `time`. Paired differences are tested with the
  Nadeau–Bengio corrected resampled t-test.
* **Survival models.** Pre-processing (log of skewed labs, standardisation) is
  fitted inside each fold. Metrics: Harrell's and Uno's C, time-dependent AUC
  (30/60/90/180 d), Brier score, IBS against a KM null model, bootstrap
  optimism correction, calibration slope, Schoenfeld PH tests.
* **External validation.** First ICD-9 428.x admission. Labs from 6 h before to
  24 h after admission; EF from echo reports of the index stay or the year
  before; units harmonised; primary endpoint 90-day all-cause mortality;
  cross-fitted recalibration; subgroup analysis.
